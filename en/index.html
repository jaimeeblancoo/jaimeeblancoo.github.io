Featured project

SMARTGRID_ES / ACADEMIC MODELPYTHON ↗
MICROGRID / REINFORCEMENT LEARNING

ARTIFICIAL INTELLIGENCE · ACADEMIC TEAM PROJECT

SmartGrid-ES

A simplified electrical microgrid for studying energy management decisions through reinforcement learning. The project uses a custom Gymnasium environment and a Q-learning agent, with synthetic scenarios for demand, renewable generation and prices.

Includes scenario evaluation, fuzzy-logic risk analysis and a Streamlit dashboard for exploring results. It also includes an optional particle swarm optimisation (PSO) experiment to tune reward function weights.

Python Gymnasium Q-learning Streamlit Fuzzy logic
